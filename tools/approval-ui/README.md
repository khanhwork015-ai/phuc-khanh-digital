# Web duyệt bài (approval-ui)

Máy chủ duyệt bài chạy trên máy vận hành, không chạy cùng website Next.js.

- `server.py`: API và logic (tài khoản, PIN, 2 lớp duyệt, hẹn đăng, gắn brand với Fanpage Meta).
- `index.html`: giao diện một trang.
- Thư mục `data/` (tài khoản, PIN, phiên đăng nhập, danh sách Fanpage) KHÔNG đưa lên git.
